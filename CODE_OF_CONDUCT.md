# Code of Conduct

## Our standards

This project exists for a school community that includes minors. Everyone who participates in
the repository, issues, reviews, or the deployed site is expected to:

- Discuss ideas without attacking people.
- Assume good faith, and ask a clarifying question before escalating.
- Respect privacy: no real names, photos, contact details, or screenshots of other people.
- Keep criticism specific and actionable.
- Step away when angry. A reply sent an hour later is usually better.

Unacceptable behavior includes harassment, insults, discriminatory language, sexualized
comments or images, threats, doxxing, deliberate disruption, and publishing someone's personal
information.

## Scope

This code applies to project spaces: the repository, issues, pull requests, reviews, and any
chat created for the project. It does not replace the school's student guidance rules, which
continue to apply to students at school.

## Reporting

Report a problem to the repository maintainer through GitHub, or to the teacher advisor if the
issue involves a student's safety. Reports are handled privately. Do not open a public issue
that contains the harmful content or names the person involved.

## Consequences

The maintainer may, depending on severity:

1. Ask for a change in behavior.
2. Remove content or comments.
3. Close a discussion or reject a contribution.
4. Block an account from the repository.
5. Refer the matter to the teacher advisor or the school.

Safety reports involving minors are always escalated; they are not handled only by the
maintainer.

## Attribution

This is a short, project-specific code of conduct. It is not a legal document and makes no
promise of a formal investigation process beyond what the school and GitHub provide.
