# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.1.x (current prototype) | Best effort, pre-release |

The project is a prototype. Security fixes are applied to the `main` branch; there are no
backports to older commits.

## Reporting a vulnerability

**Do not open a public issue.**

Use GitHub's private vulnerability reporting: repository → **Security** → **Report a
vulnerability**. If that is unavailable, contact the maintainer listed on the repository
profile.

Please include:

- A description of the issue and the affected route or file.
- Steps to reproduce, with a test account and no real student data.
- The impact you believe it has.
- Any suggested fix, if you have one.

## What to expect

- Acknowledgement within 7 days.
- An assessment and a target fix date, or an explanation if the report is out of scope.
- Credit in the fix commit if you want it.

This is a volunteer-run project; response times are best effort, not a commercial SLA.

## Scope

In scope:

- Authentication and session handling.
- Authorization bypasses (student reaching moderator actions).
- Cross-site scripting, CSRF, SQL injection.
- Personal data exposure.
- Open redirects.
- Denial of service caused by a single cheap request.

Out of scope:

- Attacks that require a compromised device or an already-stolen password.
- Social engineering of students or staff.
- Reports generated by automated scanners without a demonstrated impact.
- Denial-of-service testing against the production site, or any testing involving real student
  data.

## Safe harbor

We will not pursue action against good-faith research that follows this policy, stays within the
scope above, avoids privacy violations, and does not degrade the service for real users.

## Before you test

- Use a local instance: `pnpm dev` against a seeded database.
- Never attempt to access, modify, or exfiltrate data belonging to other people.
- If you accidentally encounter personal data, stop, do not save it, and tell the maintainer.
- Do not test against the school's network or devices without written permission.
