# ルートとフォームのエンドポイント

> 日本語版です。英語版が正本です: [English](../04-routes-and-api.md)

これらのエンドポイントは、このアプリケーションの HTML フォームを処理するために用意しています。**バージョン付きの公開 API ではありません。** 将来モバイルクライアントを作るなら、バージョンを明示した JSON API が別途必要です。

## 1. ページ

| パス | アクセス | 目的 |
| --- | --- | --- |
| `/` | 公開 | ヒーロー、最新スレッド 8 件、ボード一覧、投稿ルール |
| `/b/[slug]` | 公開 | ボード内の表示中のスレッド。1 ページ 20 件。固定が先、次に活動順または人気順 |
| `/t/[id]` | 公開 | 全投稿を含むスレッド、返信フォーム、通報ボタン |
| `/t/[id]/edit` | 作成者 | 投稿から 15 分以内に、タイトル・最初の投稿・タグを編集 |
| `/t/[id]/export` | 公開 | スレッドをプレーンテキストのファイルとしてダウンロード |
| `/u/[username]` | 公開 | プロフィール。参加日、表示中のスレッド数と投稿数、最近のスレッドと投稿 |
| `/new` | ログイン済み | スレッド作成。ゲストは `/login?next=/new` へリダイレクト |
| `/login` | 公開 | ログインフォーム。ログイン済みの利用者はリダイレクト |
| `/register` | 公開 | 登録フォーム。最初のアカウントは `ADMIN` になる |
| `/bookmarks` | ログイン済み | 保存したスレッドの一覧 |
| `/search` | 公開 | タイトルと本文の検索、タグ絞り込み、新着順・人気順 |
| `/moderation` | モデレーター／管理者 | 未処理の通報、自動フラグ、最近の監査ログ。それ以外の利用者はリダイレクト |
| `/rules` | 公開 | コミュニティルール。表示言語に合わせて出し分ける |
| `/privacy` | 公開 | プライバシー通知。保存する情報、Cookie、保存期間、閲覧できる人 |
| `/moderation-policy` | 公開 | 通報、自動フラグ、異議申し立て、エスカレーションの扱い |
| `/health` | 公開 | JSON の稼働確認。`{"status":"ok","database":"ok"}` を返し、データベースに触れないときは 503 |
| 未知のパス | 公開 | カスタム 404 |

すべてのページはリクエストごとにサーバーで描画します。クライアント側でデータを取得することはありません。

### レート制限

すべてプロセス内の固定ウィンドウで、IP かアカウントをキーにします。1 つの教室が同じ学校の IP を共有することがあるため、既定値はかなり緩めにしています。

| 操作 | 既定の制限 |
| --- | --- |
| ログイン | IP + ユーザー名ごとに 10 分 10 回 |
| 登録 | IP ごとに 1 時間 60 回 |
| スレッド作成 | アカウントごとに 1 時間 10 回 |
| 返信 | アカウントごとに 1 時間 60 回 |
| 通報 | アカウントごとに 1 日 30 回 |
| いいね／保存 | アカウントごとに 1 時間 300 回 |

ログインに成功すると、その IP + ユーザー名のカウンターを消します。パスワードを一度打ち間違えてから正しく入れても、ロックアウトには近づきません。制限に当たると `error=rate-limited` を付けて元のページへ戻します。レスポンスはリダイレクトなので `Retry-After` は返しません。再起動するとカウンターは消えます。

制限はコードを直さずに環境変数で変えられます。`RATE_LIMIT_<NAME>_LIMIT` と `RATE_LIMIT_<NAME>_WINDOW_MIN` の組で、`<NAME>` は `LOGIN`、`REGISTER`、`THREAD`、`REPLY`、`REPORT`、`LIKE`、`BOOKMARK` のいずれかです。たとえば以前のログイン制限に戻すなら、`RATE_LIMIT_LOGIN_LIMIT=5` と `RATE_LIMIT_LOGIN_WINDOW_MIN=10` を設定します。詳しくは `docs/ja/07-operations.md` の第 2 節を見てください。

### 検索と並べ替え

`/search` は `q`（100 文字まで）、`tag`（小文字に正規化）、`sort=latest|hot` を受け取ります。`q` はスレッドのタイトルと、表示中の返信の本文を `contains` で照合し、結果は 100 件までです。`hot` は「いいね × 3 + 保存 × 2 + 返信数 + 直近 72 時間の活動への加点（最大 3）」で並べます。ボードページも同じ `sort` を受け取り、さらに 1 始まりの `page` を受け取ります。1 ページは 20 件です。`page` が最後のページを超えたときは最後のページに丸め、ページ 1 は `?page=1` を付けない URL を正とします。`sort=hot` では上位 100 件をアプリケーション側で並べ替えてからページに分けます。

方針ページは `src/lib/policies.ts` にある静的な二言語の本文を表示します。文面をコードとして持つので、英語と日本語は同じコミットで変わります。公開前に、担当教員がこの文面を承認する必要があります。

## 2. 変更系エンドポイント

すべてのエンドポイントは `application/x-www-form-urlencoded` または `multipart/form-data`（標準の HTML フォーム形式）を受け取ります。クロスオリジンの `Origin` ヘッダーは拒否し、成功時は `303 See Other` を返してブラウザに `GET` を行わせます。

### `POST /api/auth/register`

| フィールド | 必須 | ルール |
| --- | --- | --- |
| `username` | はい | 3〜20 文字、`[A-Za-z0-9_]`、小文字化 |
| `email` | いいえ | 有効なアドレス、254 文字以内、一意 |
| `password` | はい | 10〜200 文字、前後の空白は削除しない |
| `next` | いいえ | 同一サイトのパスのみ |

- 成功: セッション Cookie を設定し、`next` または `/` へリダイレクトします。
- 失敗: `/register?error=<code>` へリダイレクトします。パスワードを画面に戻すことはありません。
- コード: `invalid-input`、`username-taken`、`email-taken`。

### `POST /api/auth/login`

| フィールド | 必須 |
| --- | --- |
| `username` | はい |
| `password` | はい |
| `next` | いいえ |

- 成功: セッション Cookie を設定し、`next` または `/` へリダイレクトします。
- 失敗: `/login?error=invalid-credentials`。利用者が存在しない場合もパスワードが違う場合も、同じメッセージを返します。
- IP + ユーザー名ごとに 10 分 10 回を超えると `error=rate-limited` を返します。ログインに成功するとカウンターは消えます。

### `POST /api/auth/logout`

- 有効な Cookie があればセッション行を削除し、Cookie を消して `/?notice=signed-out` へリダイレクトします。

### `POST /api/locale`

| フィールド | 必須 | 値 |
| --- | --- | --- |
| `locale` | はい | `en` または `ja` |

- 画面は、利用者が切り替えるまで日本語です。1 年間有効な `locale` Cookie を設定し、同じホスト上の直前のページへ戻します。使える `Referer` がないときは `/` へ戻します。
- 未知の値は無視します。その場合も、現在のページはそのまま再読み込みします。

### `POST /api/threads`

| フィールド | 必須 | ルール |
| --- | --- | --- |
| `boardId` | はい | 存在し、アーカイブされていないボード |
| `title` | はい | 3〜120 文字 |
| `body` | はい | 1〜10,000 文字 |
| `tags` | いいえ | スペースかカンマ区切り、先頭の `#` は任意、最大 5 個 |

- 認証: ログイン済みの利用者。
- 成功: `Thread` と最初の `Post` を原子的に作成し、`/t/<id>` へリダイレクトします。
- 失敗: `/new?board=<slug>&error=<code>`。
- コード: `board-not-found`、`invalid-input`、`login-required`。

### `POST /api/threads/[id]/posts`

| フィールド | 必須 | ルール |
| --- | --- | --- |
| `body` | はい | 1〜10,000 文字 |
| `tags` | いいえ | スペースかカンマ区切り、先頭の `#` は任意、最大 5 個 |

- 認証: ログイン済みの利用者。
- 前提: スレッドが存在し、削除されておらず、ロックされていないこと。
- 成功: `Post` を挿入し、同じトランザクションで `Thread.lastPostAt` を更新して、`/t/<id>#p-<postId>` へリダイレクトします。
- 失敗コード: `thread-locked`、`invalid-input`、`thread-not-found`。

### `POST /api/threads/[id]/edit`

| フィールド | 必須 | ルール |
| --- | --- | --- |
| `title` | はい | 3〜120 文字 |
| `body` | はい | 1〜10,000 文字。最初の投稿を置き換える |
| `tags` | いいえ | スレッド作成と同じルール。現在のタグ一式を置き換える |

- 認証: スレッドの作成者本人のみ。`Thread.createdAt` から 15 分以内に限ります。
- 前提: スレッドが存在し、削除されておらず、ロックされていないこと。
- 成功: タイトルと最初の投稿を更新し、`Thread.editedAt` を設定し、タグを置き換えて `/t/<id>?notice=thread-edited` へリダイレクトします。
- 編集後の本文が要注意語に一致した場合、その投稿に未処理の `AUTO` 通報がなければ 1 件だけ作ります。
- 失敗コード: `edit-not-allowed`、`invalid-input`、`not-found`。

### `POST /api/threads/[id]/lock`

- 認証: `MODERATOR` または `ADMIN`。本文は不要です。
- `isLocked` を反転し、スレッドへ戻します。
- 失敗コード: `forbidden`、`thread-not-found`。

### `POST /api/threads/[id]/delete`

- 認証: `MODERATOR` または `ADMIN`。本文は不要です。
- `isDeleted = true` にして、ボードへリダイレクトします。
- 失敗コード: `forbidden`、`thread-not-found`。

### `POST /api/posts/[id]/delete`

- 認証: `MODERATOR` または `ADMIN`。本文は不要です。
- `isDeleted = true` にして、スレッドへリダイレクトします。投稿はプレースホルダーとして表示され続けます。
- 失敗コード: `forbidden`、`not-found`。

### `POST /api/posts/[id]/like`

- 認証: ログイン済みの利用者。本文は不要です。
- 利用者 1 人につき投稿 1 件のいいねを切り替えます。`Post.likeCount` とスレッド全体の `Thread.likeCount` を同じトランザクションで更新します。
- `/t/<threadId>#p-<postId>` へ戻します。

### `POST /api/threads/[id]/bookmark`

- 認証: ログイン済みの利用者。本文は不要です。
- 利用者 1 人につきスレッド 1 件の保存を切り替え、`Thread.bookmarkCount` を更新します。
- 同じホスト上の直前のページ、またはスレッドページへ戻します。

### `POST /api/reports`

| フィールド | 必須 | ルール |
| --- | --- | --- |
| `postId` | はい | 存在する投稿 |
| `reason` | はい | 3〜500 文字 |

- 認証: ログイン済みの利用者。
- 成功: `Report` を作成し、`?notice=reported` を付けてスレッドへリダイレクトします。
- 失敗コード: `report-invalid`。

### `POST /api/reports/[id]/resolve`

| フィールド | 必須 | 値 |
| --- | --- | --- |
| `action` | はい | `remove` または `dismiss` |

- 認証: `MODERATOR` または `ADMIN`。
- `remove`: 通報された投稿を論理削除し、通報を `removed` にします。
- `dismiss`: 投稿はそのままにし、通報を `dismissed` にします。
- どちらの場合も `/moderation` へリダイレクトします。

### 未読の表示

`/`、`/b/[slug]`、`/t/[id]` は、ログイン中の利用者の `ThreadRead` を読みます。その行がなければ、または `Thread.lastPostAt` が `lastReadAt` より新しければ、スレッドに「新着」を表示します。スレッドページを描画するときに、現在時刻でその行を upsert します。ゲストは既読状態を持たないため、バッジは表示しません。書き込みは冪等で、保存するのは時刻だけです。

## 3. エラー処理

JSON のエラー形式はありません。利用者に見せる失敗は、クエリ文字列に短いコードを付けて該当ページへ戻します。コードを英語の文に対応付けるのは `src/lib/messages.ts` です。未知のコードは汎用の「フォームを確認してください」に落ちるため、手で作った URL からページに任意のテキストを差し込むことはできません。

想定外の失敗（データベースの停止、未処理の例外）は Next.js が 500 として返します。公開前にエラー監視を追加してください。`docs/ja/07-operations.md` を参照してください。

## 4. Cookie

| 属性 | 値 | 理由 |
| --- | --- | --- |
| 名前 | `toyooka_session` | |
| 値 | 16 進 64 文字（32 バイトのランダム） | 256 ビットのエントロピー |
| `HttpOnly` | true | JavaScript から読めない |
| `SameSite` | `Lax` | ほとんどのクロスサイトフォーム送信を防ぐ |
| `Secure` | 本番では true | HTTPS が必要 |
| `Path` | `/` | |
| `Expires` | 30 日 | |

2 つ目の Cookie `locale` は、画面の表示言語（`en` または `ja`）を 1 年間保存します。この Cookie がないときは日本語です。こちらも `HttpOnly` と `SameSite=Lax` を設定します。身元を示す情報は含まないので、消しても問題ありません。

`COOKIE_SECURE=false` は、学校の LAN で平文 HTTP を使う場合のためだけに用意しています。公開インターネットでは使わないでください。

## 5. CSRF とオリジンの確認

`SameSite=Lax` があるため、クロスサイトの POST で Cookie が設定されることはすでに防げています。そのうえで多層防御として、すべての POST ハンドラーが `isSameOrigin()` を呼び、`Origin` ヘッダーが別ホストを指していれば拒否します。`Origin` ヘッダーのないリクエスト（curl や一部のプライバシーツール）は許可します。攻撃者が、クロスサイトのフォーム送信でブラウザに `Origin` を省かせることはできないからです。

## 6. キャッシュ

どのエンドポイントもキャッシュしません。ページは動的です。レスポンスのヘッダーにはログイン中の利用者名が入るため、アプリの前段に置いた CDN にレスポンスをキャッシュさせてはいけません。
