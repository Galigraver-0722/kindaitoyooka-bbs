# インターフェース設計

Kinjoは、`f7577f2` の元のレイアウトを復元し、ライトモードに AQUA POP、ダークモードに SIGNAL を使います。元のデザインから変更するのは名称とロゴです。ロゴはアクア色の吹き出しに「近」をベクターで描きます。

元のヘッダー、簡潔な紹介、ボードの活動グラフ、サイドバー、フィルター、カード一覧、ダークモードの行形式の一覧、丸い投稿ボタンを、元の余白と装飾で表示します。後から加えた街並みとダッシュボードは表示しません。

`src/components/theme/themed-page.tsx` は `home-d-css.ts` / `home-b-css.ts` と `pages-css.ts` の後に、名称とロゴ用の `logo-css.ts` と操作演出用の `motion-css.ts`を適用します。試作の `redesign-css.ts`、`kinjo-css.ts`、`polish-css.ts`、`aqua-css.ts` は保存しますが適用しません。活動グラフのコンポーネントも今後の利用に備えて残します。

キーボードによる検索、ボードメニューの終了操作、本文へのスキップリンクを維持します。検索、認証、お知らせ、管理、投稿、リアクション、言語とテーマの操作は既存の処理を使います。投稿総数から削除済みの投稿とスレッドを除きます。外部フォントや画像の通信は不要です。

日本語と英語、明暗テーマ、デスクトップと携帯幅、キーボード操作、ページ移動、動きを減らす設定、表示用・配布用・タブ用ロゴの一致を確認します。ローカルのスクリーンショットはコミットしません。

## 動きと操作

`motion-css.ts` で操作部品、カード、メニュー、シート、ドロワーの動きをそろえます。いいね・保存ではボタン全体ではなくアイコンを動かし、タッチ端末ではホバー時の浮き上がりを抑えます。ヘッダーは下方向28px・上方向14pxの移動を基準に、描画フレームごとに更新します。フォーカス中やメニュー展開中は表示を維持します。通知とお知らせは閉じる動きが終わってから取り除きます。テーマはページ全体を再読み込みせず、短い切替演出の間にサーバーコンポーネントを更新してブラウザーやフォームの状態を保ちます。動きを減らす設定では演出を無効にします。
