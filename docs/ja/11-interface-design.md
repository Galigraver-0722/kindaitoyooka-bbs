# インターフェース設計

新しいキャンパス・コモンズのデザインでは、従来の AQUA POP と SIGNAL の個別レイアウトを、明暗の配色を持つ共通のナビゲーションとカードに置き換えます。ADR-0018 の視覚仕様と `local/designs/` の試作メモに優先します。

- 共通ヘッダーに検索、ボード、お知らせ、アカウント、言語、テーマの操作をまとめます。Cmd/Ctrl-K で検索へ移動できます。ボードメニューは Escape と外側のクリックで閉じます。
- ホームには掲示板の紹介と投稿・閲覧への入口を置きます。装飾は HTML/CSS だけで描き、外部通信は不要です。支援技術には読み上げさせません。
- フィード、ボード、プロフィールのスレッド一覧は両テーマで同じカードを使います。検索、並び替え、ページ分割、権限判定は既存の処理を維持します。
- フォーム、議論、プロフィール、方針文書、管理画面、エラー画面に共通の余白、境界線、文字組みを適用します。フッターから各方針へ移動できます。
- 登場アニメーションは一度だけ実行し、ホバー時の動きは精密なポインターに限定します。動きを減らす設定ではアニメーションとトランジションを無効にします。フォーカスを明示し、本文へのスキップリンクを設けます。
- 新しい文言は `src/lib/locales.ts` の両辞書に置きます。外部フォントやアニメーションライブラリは不要です。

最終的なテーマ層は `src/components/theme/redesign-css.ts` です。既存の構造スタイルの後に適用します。`shell-interactions.tsx` がナビゲーションの補助動作を担当し、通常のリンクと GET 検索フォームは JavaScript なしでも利用できます。

明暗両テーマ、デスクトップと携帯幅、日本語と英語、動きを減らす設定、キーボード検索、メニューの終了、ページ移動を確認します。認証が必要な画面はローカルのテストアカウントで確認します。生徒の情報を含む画像をリポジトリにコミットしてはいけません。
