# Kinjo：漢字のロゴと掲示板レイアウト

新しいマークは **近** を独自の SVG の線で描きます。しんにょうの下部が、文字全体を支えるように伸びます。深い緑の四角、温かい白の線、淡い緑の小さな角印でアイコンを構成します。ヘッダーでは正式名称の **近所** を並べ、ローマ字の表記は補助的に使います。

- `src/components/kinjo-mark.tsx`：ヘッダー、マストヘッド、フッター用のインラインベクター。
- `src/app/icon.svg`：Next.js のメタデータ規約に従うブラウザーのタブアイコン。
- `public/kinjo-mark.svg`：`/kinjo-mark.svg` で取得できる単独のロゴ素材。

マーク自体はフォントや外部素材に依存しません。3つのファイルで線の形と比率をそろえてください。名称の文字組みにはシステムの明朝体を使いますが、小さなマークは常にベクターです。明暗どちらでも枠がコントラストを保ちます。読み上げ名はホームリンクに付け、繰り返し使う装飾マークは支援技術から隠します。

## レイアウト

掲示板風のレイアウトは試作後、所有者の要望で取り下げました。街並み、丸いスレッドカード、一覧の下のグラフを持つ以前のKinjoデザインへ戻します。試作から残すのは承認された漢字のロゴだけです。`src/components/theme/logo-css.ts` は配置や配色を変えず、ヘッダーとフッターのロゴを整えます。
