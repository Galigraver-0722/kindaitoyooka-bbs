# Kinjo：アクア色の吹き出しロゴ

独自のベクターで描く **近** を、角の丸い吹き出しに収めます。深緑の四角、クリーム色の線、黄緑の角印に代わり、AQUA POP のシアン（`#12BFD1`）、紺色の輪郭と文字（`#062330`）、丸い線端を使います。ダークモードのヘッダーでは SIGNAL のシアン（`#5AE6EC`）に合わせます。

- `src/components/kinjo-mark.tsx`：ホームリンク内の装飾用ロゴ。
- `src/app/icon.svg`：Next.js のメタデータ規約に従うタブアイコン。
- `public/kinjo-mark.svg`：`/kinjo-mark.svg` で取得できる同じ形の単独素材。

3つのファイルで外形、文字、比率をそろえます。読み上げ名はホームリンクに付け、SVGは支援技術から隠します。フォントや外部素材への依存はありません。

元の AQUA POP と SIGNAL の配置を復元し、名称とロゴをKinjoへ変更します。`src/components/theme/logo-css.ts` はロゴの寸法、ダークモードの色、フォーカス時だけ表示するスキップリンクを担当します。現在の配置は[インターフェース設計](11-interface-design.md)を参照してください。後から試作した街並みのデザインは適用しません。
