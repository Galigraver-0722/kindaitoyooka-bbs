## この文書群の約束

- **コード、コマンド、ファイル名、URL、エラーメッセージは英語のまま**書きます。翻訳すると動かなくなるためです。
- 数字、上限値、フィールド名はコードと一致させます。食い違ったら、コードか文書のどちらかが誤りです。同じプルリクエストで直してください。
- 安全に関する記述は「願望」ではなく「要件」として書きます。
- 法律に関する記述は計画のための要約であり、法的助言ではありません。何が適用されるかは担当教員と学校の管理職が判断します。
- 英語版と日本語版は同じプルリクエストで更新します。片方だけ直すと、どちらが正しいか分からなくなります。
