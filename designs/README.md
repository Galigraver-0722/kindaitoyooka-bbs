# 设计方向

日期：2026-10-24 · 状态：F 已选定（D 与 B 各自独立）· 未改动应用代码

这些页面是**视觉方案原型**，不是实现。它们用同一份内容、同一套信息结构，只换视觉语言，方便直接比较。这是选型当时的记录：`e-dual.html` 是「一个页面内切换」的合并实验，最终没有采用；选定的是 F（两套独立页面）。

- `index.html` — 总览页（缩略图 + 调色板 + 链接）
- `a-sky.html` / `b-signal.html` / `c-shinbun.html` / `d-aqua.html` — 四个备选方向
- `e-dual.html` — 合并版：浅色 AQUA POP，深色 SIGNAL，页头开关
- `shots/` — 当前应用的截图（`app-*`）与最终方案 F 的整页截图（`f-b-*`、`f-d-*`）。这个目录不进版本库；A–E 的截图属于选型过程，比对完即删，原型 HTML 本身仍在仓库里

## 共同的信息结构

五个方案都包含同一批元素，所以比较的是设计而不是功能：

- 常驻搜索框（桌面在导航栏，手机单独一行）
- 首页标题区 + 板块入口
- 主题列表：板块、标签、点赞数、回复数、作者、时间、收藏图标
- 右下角发布按钮
- 每页 6–8 条日文示例内容

## 参考脉络

| 方向 | 参考来源 |
| --- | --- |
| A 空 | 氛围式界面（Apple visionOS 的层次感）、Swiss 排版的留白、当代 SaaS 的磨砂面板 |
| B 信号 | 终端界面与监控仪表盘（Linear、Vercel 的深色系统）、数据表格排版 |
| C 青版 | 日本报纸组版（明朝体标题、竖排报名、段栏与点线）、瑞士编辑设计的网格纪律 |
| D 図形 | 新粗野主义（硬边框、硬投影、贴纸式徽章）、Bauhaus 的几何色块 |

## A — 空 / SKY

**概念**：整个站点像一片天空。内容是浮在天空上的玻璃板。

- **配色**：`#F4FBFF` 底、`#0B2A38` 墨、`#12B4C9` 青、`#0A6E82` 深青，白色半透明面板
- **字体**：无衬线正文 + 等宽数字
- **签名元素**：巨大的太阳光晕、缓慢旋转的虚线轨道、玻璃面板、青色高亮马克笔
- **优点**：最安静、最易读，字号和对比度最容易做达标；情绪友好，适合新生
- **风险**：最接近「常见的现代 SaaS」，个性化最弱；半透明面板在低端设备上滚动性能一般
- **落地成本**：最低。现有布局基本可复用，主要是换色板、加玻璃层与光晕，约 1–1.5 天
- **适合**：想让页面「好看但有礼貌」，不吓到老师与家长

## B — 信号 / SIGNAL

**概念**：学校的控制台。所有帖子都是数据行，顶部有实时波形，中间是网格。

- **配色**：`#040F16` 底、`#5AE6EC` 霓虹青、`#2FA9BE` 深青、`#DCF6F8` 文字
- **字体**：等宽字承担元数据与导航，粗无衬线承担标题
- **签名元素**：左栏竖排刻度、扫描线纹理、点线引导、LIVE 波形、编号 `B–01` 板块
- **优点**：最「酷」，信息密度最高，一屏能读 6 条主题；技术社团会喜欢
- **风险**：深色模式需要单独做一套对比度审查；长时间阅读比浅色累；长辈/老师可能觉得像游戏界面
- **落地成本**：中高。需要第二套色板、深色下的图片/徽章适配、对比度复核，约 3–4 天
- **适合**：想要「一眼记住」的强个性，且能接受深色为主

## C — 青版 / SHINBUN

**概念**：把 BBS 做成一份校报。首页是「一面」，主题列表是报纸索引。

- **配色**：`#F7F8F4` 纸白、`#101E1D` 墨、`#0E7C8C` 青色专色
- **字体**：明朝体标题 + 明朝体正文 + 少量无衬线标签
- **签名元素**：左侧竖排「豊岡学園」、3px 双线报头、点线目录、`［文化祭］` 方括号标签、报号与日期
- **优点**：最有文化辨识度，和「学校」这件事天然贴合；适合长期存档型内容（问答、公告）
- **风险**：明朝体小字在手机上偏细；版面复杂度高，其他页面（发帖、设置、审核）都要重新设计；只有系统明朝体可用，没有网络字体
- **落地成本**：最高。约 4–5 天，且需要逐页重排
- **适合**：想做成「学校自己的媒体」，而不只是一个论坛

## D — 図形 / AQUA POP

**概念**：贴纸与色块。每张卡片都像被贴在墙上，边框和投影都是硬的。

- **配色**：`#F0FBFE` 底、`#12BFD1` 青、`#A9E5FF` 浅蓝、`#062330` 墨
- **字体**：粗无衬线（800）+ 等宽字标签
- **签名元素**：2px 描边、4–8px 硬投影、旋转贴纸、青色块面高亮、点阵底纹、柱状板块活跃度
- **优点**：最年轻、最抢眼、最有「想点一下」的冲动；层级靠边框和投影表达，不依赖颜色深浅
- **风险**：重边框在数据密集页会显得吵；大量投影需要控制，否则失去焦点
- **落地成本**：中。需要一套描边/投影 token、卡片组件替代列表行，约 2–3 天
- **适合**：想让低年级学生愿意用、愿意点


## F — 二つの独立ページ（最终方向）

**两套设计完全独立，只共享一个切换按钮。**

- `f-d.html`：最开始的 D 原版，原封不动；页头加了一个「DARK」按钮。
- `f-b.html`：最开始的 B 原版，原封不动；页头加了一个「LIGHT」按钮。
- 没有共享 DOM，也没有共享 CSS。改 D 不会碰到 B，反之亦然。
- 唯一的「妥协」就是那个按钮：两页各有一个，外观按各自的设计做（D 是粗边框胶囊，B 是等宽小方块）。

**切换**：点按钮后，一团目标页面的底色从按钮位置扩散盖住当前页（0.32s），然后跳转到另一个页面；新页面加载时色幕已经盖住，再用 0.26s 淡出，滚动位置由 `sessionStorage` 恢复。视觉上像一次换材质，不是一次普通跳转。

**代价**：跨页切换有真实的加载时间（本地即时，线上约 100–300ms，被色幕盖住）；两套样式和两份文案要各自维护。换来的是两套设计都不被对方约束。

**已验证**：1440 与 390 两种宽度都无横向溢出、无控制台报错；双向切换正常；色幕结束后 `wiping` 类会移除；滚动位置在新页面可恢复（受目标页高度限制）。

**成本**：每套页面按原设计落地；切换按钮 + 色幕 + 主题记录约 0.5 天。

## 怎么选

| 如果你想要 | 选 |
| --- | --- |
| 稳妥、好读、老师家长都能接受 | A |
| 强烈的科技个性、一屏信息最多 | B |
| 有学校气质、像一份真正的校报 | C |
| 年轻、活泼、一眼记住 | D |

也可以混合：用 C 的排版权重（大标题、细线、索引）+ D 的青色块面与硬投影，得到「校报 + 波普」的折中；或用 A 的底色 + C 的明朝体标题，得到更温和的编辑风。

## 已验证

- E 的开关已验证：`data-theme` 切换、标签与 `aria-pressed` 同步、刷新后保持、系统偏好作为初始值、双向切换都能复位色幕、`prefers-reduced-motion` 下直接切换、无 JS 报错
- 1440 / 900 / 768 / 390 下两种主题均无横向溢出
- 页面在 `prefers-reduced-motion` 下停止动画
- 所有字体均为系统字体，无外部请求
